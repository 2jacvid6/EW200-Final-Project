### How to play
1. Clone this repository
2. Install 'pygame-ce' with 'pip install pygame-ce'
3. run game.py, 'python3 game.py'
------------------------------------------------------
1. Use the arrow keys to control the orange player, and use WASD to control the blue player
2. Hit the ball towards the goal to score, while defending your goal at the same time

### Soccer game features
1. Physical (+4)
2. Multiplayer (+4)
3. Keyboard King (+2)
4. Points-R-Us (+4)
